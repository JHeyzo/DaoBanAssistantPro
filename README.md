## 本版改动（v0.11.3）

### 排班模型重做
- **一天可叠多个班次**：比如白班+值班同一天，不用再拆成两天
- **班次语义标记**：每个班次可标记为 工作 / 值班 / 休息。改名、调序、删班次不再弄断闹钟和休息规则
- **休息规则**（新功能）：休息跟星期走 → 用规则；休息跟节奏走 → 写进周期
  - **跟随值班**：值班在周几 → 休息在周几（可逐行自定义，内置"行政班值班制"等预设）
  - **固定星期**：每周固定几天休息（如双休）
  - **不用规则**：休息日写进周期里（兼容老用法，如三班倒）
- **模板系统拆除**：内置模板库与「我的模板」删除。新建只留「空白模板」+「导入配置文件」；编辑页可「导出配置文件」

### 日历视觉重做
- 扁平布局，无卡片容器
- 日期收进圆角方章内，班次简称在数字下方
- 白班：浅蓝章（`#EEF4FF` 底 / `#9EC1F5` 边 / `#2F7CF6` 字）
- 值班：蓝章右上斜切 + **实心红三角**悬浮（两片分开，中间留缝）
- 休息：灰章；今天：蓝色实心章
- 法定节假日：农历前加绿色「休」字（原红色文字已去掉）；调休上班日：蓝色「班」字

### 系统闹钟通道（ColorOS + OPPO 手表）
- App **不再自己响铃**：每天 00:30 按排班表把当天闹钟静默写入系统时钟（标准 `ACTION_SET_ALARM` + `SKIP_UI`）
- 系统时钟响铃时，OPPO 手表通过「手机闹钟提醒」同步震动（实测免打扰+睡眠模式下手表仍跟随）
- 「值班次日闹钟」改按语义标记自动认值班，不用再手动选班种

### 其他
- 新增「黄历宜忌」开关（我的 → 设置，默认关）
- 去掉每次启动都跳的「全屏通知」授权申请

# 倒班助手Pro

自研的排班助手 App —— 从 0 到 1 用 **Flutter 构建**的完全自有代码（`com.daoban.shiftassistantpro`）。

**排班日历 · 班次闹钟 · 待办日程**：为倒班人群打造，一套 App 搞定倒班生活的日常。

> 无账号 · 无广告 · 无后端 · 纯本地离线 · 开源（[MIT](LICENSE)）

---

## ✨ 功能特性

### 📅 排班日历
- **周期表可自由编辑**：班次定义只需配一次（时间 / 颜色 / 联动闹钟 / 语义标记），周期表里每天可叠多个班次；周期长度 1–60 天
- **语义标记**：班次标记为 工作 / 值班 / 休息 后，值班次日闹钟、休息规则都按标记认，不怕改名
- **休息规则**：跟随值班 / 固定星期 / 不用规则三种模式，休息日自动算出
- **编辑器实时预览**：改班次时间、周期或休息规则，未来 14 天的班次随手改随手看
- **按天改班（换班 / 请假覆盖）**：某一天可单独指定班次，不动整套排班
- **月视图**：扁平布局，日期收进圆角方章；值班日右上角红折角一眼识别
- **底栏信息卡**：日期 + 农历 + 班次与时间 + 其他班组；多班次的日子每条班次单独一行
- **农历 + 节假日**：每格显示农历日 / 节气 / 节日；法定节假日标「休」、调休上班日标「班」；内置 2025/2026 国务院放假安排
- **多套排班表按日期衔接**：每套方案可带生效时段，按日期自动切换
- **桌面小组件**：本周条 / 今日卡 / 整月三种尺寸

### ⏰ 联动班次闹钟
- **按班次自动响铃**：每个班次可独立设置响铃时间与开关，跟随排班自动排定
- **一个班次可以挂多条闹钟（最多 6 条）**：每条能起名字
- **值班次日闹钟**：前一天值班时，次日第一条闹钟改用指定时间（按语义标记自动识别值班）
- **系统时钟通道（本 fork）**：闹钟写入系统时钟响铃，OPPO 手表同步跟随
- **自定义闹钟**：一次性 / 每天 / 每周，独立于排班

### ✅ 待办日程
- 待办事项管理，支持重复规则
- 待办提醒走普通通知

## 🛠 技术栈
- Flutter + Dart
- Drift (SQLite) 本地数据库
- 无后端，纯离线

## 📁 项目结构
```
app/
  lib/
    core/        # 基础组件、设计令牌
    domain/      # 排班领域模型
    data/        # 数据库与仓库
    features/    # 功能模块（日历、闹钟、待办、我的）
    state/       # 全局状态
  test/          # 单元测试
```

## 🔨 构建
```bash
cd app
flutter pub get
# 如有数据库变更，先跑：
dart run build_runner build --delete-conflicting-outputs
flutter build apk --release
```
