## ⭐ 特色功能

- **ColorOS 深度适配**：针对 OPPO/一加 ColorOS 优化。每天 00:30 自动把当天闹钟写入手机系统时钟响铃，OPPO 手表同步震动，免打扰+睡眠模式下照样响
- **休息规则**：排班分两层——轮转周期只管"上什么班"，休息日按规则自动算。支持跟随值班（如周四值班→周六休，可自定义对应关系）、固定星期，不用再手排 28 天大表
- **班次性质**：每个班次标记上班/值班/休息，闹钟规则、休息规则、月统计都按性质自动识别，改名调序不影响

## 功能列表（v0.11.4 测试版 → v0.12.0 稳定版开发中）

### 📅 排班
- 多班次叠加：一天可安排多个班次（如白班 + 值班）
- 班次性质：工作 / 值班 / 休息。性质是班次的身份标识，改名、排序、删除不影响关联规则
- 休息规则：跟随值班（自定义值班日与休息日的对应关系）/ 固定星期 / 手动排入周期
- 按天调整：单独修改某天的班次，不影响整体排班
- 实时预览：改时间、改周期、改规则，未来 14 天的排班即时看
- 多方案按日期衔接：不同时段使用不同排班方案，自动切换
- 多班组对照：查看其他班组的排班情况
- 配置导入导出：排班方案可备份与分享

### 🗓️ 日历
- 全新视觉：扁平化圆角方章，日期与班次收纳其中
- 值班标识：日期章右上角红色折角
- 节假日标记：法定节假日显示「休」，调休工作日显示「班」
- 农历信息：农历日期、节气、节日；黄历宜忌可在设置中开启
- 月度统计：按月汇总白班、值班、休息天数
- 桌面小组件：本周条 / 今日卡 / 整月

### ⏰ 闹钟
- 班次联动：每个班次独立设置闹钟，随排班自动生效
- 多闹钟：单个班次最多 6 条，可分别命名
- 闹钟规则：每条闹钟可单独设值班次日时间、值班当天跳过
- 每日自动推送：每天 00:30 按排班表自动写入当天闹钟
- 系统时钟通道：闹钟写入系统时钟，支持 OPPO 手表同步
- 自定义闹钟：一次性 / 每日 / 每周重复
- 30 天预览：查看未来闹钟安排，可按条开关
