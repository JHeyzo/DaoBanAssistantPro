## 本版改动（v0.11.3）

### 排班模型重做
- **一天可叠多个班次**：比如白班+值班同一天，不用再拆成两天
- **班次语义标记**：每个班次可标记为 工作 / 值班 / 休息。改名、调序、删班次不再弄断闹钟和休息规则
- **休息规则**（新功能）：休息跟星期走 → 用规则；休息跟节奏走 → 写进周期
  - **跟随值班**：值班在周几 → 休息在周几（可逐行自定义，内置"行政班值班制"等预设）
  - **固定星期**：每周固定几天休息（如双休）
  - **不用规则**：休息日写进周期里（兼容老用法，如三班倒）
- **模板系统拆除**：内置模板库与「我的模板」删除。新建只留「空白模板」+「导入配置文件」；编辑页可「导出配置文件」

### 日历视觉重做
- 扁平布局，无卡片容器
- 日期收进圆角方章内，班次简称在数字下方
- 白班：浅蓝章（`#EEF4FF` 底 / `#9EC1F5` 边 / `#2F7CF6` 字）
- 值班：蓝章右上斜切 + **实心红三角**悬浮（两片分开，中间留缝）
- 休息：灰章；今天：蓝色实心章
- 法定节假日：农历前加绿色「休」字（原红色文字已去掉）；调休上班日：蓝色「班」字

### 系统闹钟通道（ColorOS + OPPO 手表）
- App **不再自己响铃**：每天 00:30 按排班表把当天闹钟静默写入系统时钟（标准 `ACTION_SET_ALARM` + `SKIP_UI`）
- 系统时钟响铃时，OPPO 手表通过「手机闹钟提醒」同步震动（实测免打扰+睡眠模式下手表仍跟随）
- 「值班次日闹钟」改按语义标记自动认值班，不用再手动选班种

### 其他
- 新增「黄历宜忌」开关（我的 → 设置，默认关）
- 去掉每次启动都跳的「全屏通知」授权申请
